# Multi-CLI Support for Pro-Vibe-Dev

## Supported AI Development CLIs

The pro-vibe-dev system works with multiple AI development tools. Here are configurations for popular options:

## 1. Claude Code (.clauderc)

```toml

name = "SwiftUI Project"
description = "Professional vibe-coded development with intelligent agent coordination"
language = "swift"
framework = "swiftui"

[agent_triggers]

testing = ["qa-testing", "tdd-enforcer", "accessibility-auditor"]

[instructions]

Follow the pro-vibe-dev system with intelligent agent coordination.

AGENT STRUCTURE:
- UI Specialists: pro-vibe-dev/ui-agents/
- Backend Specialists: pro-vibe-dev/backend-agents/

- Quality gates: Follow pro-vibe-dev/workflows/quality-gates.md
- Task execution: Follow pro-vibe-dev/workflows/task-execution.md

Always coordinate multi-agent work and trigger quality gates.
"""
```

1. Analyze task complexity using task-coordinator.md
2. Select appropriate specialist agents based on context
3. Follow quality-gates.md for validation checkpoints
4. Execute with task-execution.md methodology

QUALITY STANDARDS:
- Accessibility-first SwiftUI development (VoiceOver, Dynamic Type, WCAG AA)
- Test-driven development with 95%+ business logic coverage
- Security-conscious backend development (Keychain, input validation)
- Performance optimization (60fps UI, efficient async operations)
- Anti-overengineering mindset with clear user value focus

AGENT SELECTION:
- UI/SwiftUI work → ui-agents/ui-frontend.md + accessibility-expert.md
- Backend/API work → backend-agents/backend.md + security validation
- Testing/Quality → quality-agents/qa-testing.md + tdd-enforcer.md
- Complex coordination → coordination-agents/task-coordinator.md

Always reference the appropriate agent files and follow the established workflows.
```

## Universal Workflow Integration

### 1. Standard Commands Across All CLIs

Create a `pro-vibe-dev/cli-commands.md` file:

```markdown
# Universal CLI Commands for Pro-Vibe-Dev

## Task Coordination
**Purpose**: Analyze and coordinate complex multi-agent tasks
**Command Pattern**: `[CLI] "Use pro-vibe-dev/coordination-agents/task-coordinator.md to coordinate: [task description]"`

## Agent Selection
**UI Work**: `[CLI] "Follow pro-vibe-dev/ui-agents/ui-frontend.md to implement: [UI task]"`
**Backend Work**: `[CLI] "Follow pro-vibe-dev/backend-agents/backend.md to implement: [backend task]"`
**Quality Review**: `[CLI] "Use pro-vibe-dev/workflows/quality-gates.md to validate: [feature]"`

## Workflow Execution
**Task Execution**: `[CLI] "Follow pro-vibe-dev/workflows/task-execution.md to complete: [specific task]"`
**PRD Creation**: `[CLI] "Use pro-vibe-dev/workflows/prd-creation.md to create PRD for: [feature]"`
**Task Generation**: `[CLI] "Use pro-vibe-dev/workflows/create-tasks.md to generate tasks from: [PRD file]"`
```

### 2. CLI Detection Script

Create `scripts/detect-cli.sh`:

```bash
#!/bin/bash
# Detect available AI development CLIs and suggest optimal configuration

echo "🔍 Detecting AI Development CLIs..."

if command -v claude-code &> /dev/null; then
    echo "✅ Claude Code detected - Using .clauderc configuration"
fi

if [ -f ".cursor/settings.json" ]; then
    echo "✅ Cursor detected - Configure with .cursor/settings.json"
fi

if [ -f ".continue/config.json" ]; then
    echo "✅ Continue detected - Configure with .continue/config.json" 
fi

if [ -f ".aider.conf.yml" ]; then
    echo "✅ Aider detected - Configure with .aider.conf.yml"
fi

echo ""
echo "💡 Pro-vibe-dev works with any AI CLI using the markdown workflow files!"
echo "📚 Reference: pro-vibe-dev/cli-commands.md for universal command patterns"
```

## Benefits of Multi-CLI Support

### ✅ **Tool Flexibility**
- **Switch between CLIs** without losing workflow efficiency
- **Team members can use preferred tools** while following same methodology
- **Future-proof** - works with new AI development tools as they emerge

### ✅ **Consistent Quality**
- **Same quality standards** regardless of CLI tool used
- **Agent coordination** works across all tools
- **Workflow consistency** maintained across team and tools

### ✅ **Easy Migration**
- **No vendor lock-in** - workflows are tool-independent
- **Gradual adoption** - team can try different tools
- **Investment protection** - methodology survives tool changes

The pro-vibe-dev system is designed to be **CLI-agnostic** while providing **intelligent coordination** regardless of which AI development tool you choose! 🚀
